**Curated List of SaaS Products & Open-Source GitHub Projects**

This repository (`Awesome-Wireless-Auditing-Network-Security`) tracks notable **SaaS platforms** and **open-source projects** for **Wireless Auditing & Network Security** — Top Wireless Auditing Network Security (Opensource) 🌟 Star if you like it! 🌟. ## SaaS/Hosted Platforms



- **[Hak5 Cloud C2](https://hak5.org)**  

  Self-hosted and cloud command-and-control platform for managing Hak5 wireless auditing implants including WiFi Pineapple, Packet Squirrel, and LAN Turtle.



- **[Tenable Nessus & Tenable One](https://tenable.com)**  

  Industry-standard vulnerability assessment scanner and cloud exposure management platform for identifying network misconfigurations and wireless infrastructure flaws.



- **[Qualys Vulnerability Management (VMDR)](https://qualys.com)**  

  Cloud-native network security scanner offering continuous asset discovery, wireless network detection, and automated vulnerability prioritization.



- **[Rapid7 InsightVM](https://rapid7.com)**  

  Cloud-connected vulnerability management and live network risk assessment platform with automated remediation workflows.



- **[Ekahau Cloud & Ekahau AI Pro](https://ekahau.com)**  

  Enterprise Wi-Fi site survey, RF spectrum analysis, and cloud collaboration suite for designing and auditing secure, high-density wireless networks.



- **[Paessler PRTG Hosted Monitor](https://paessler.com)**  

  Cloud and on-premises network monitoring solution tracking wireless access points, SNMP traffic, bandwidth anomalies, and hardware health.



- **[NetSpot](https://netspotapp.com)**  

  Commercial Wi-Fi site survey, wireless signal heatmap, and channel interference troubleshooting software for macOS, Windows, and mobile platforms.



- **[Wireshark Cloud / PacketTotal](https://packettotal.com)**  

  Cloud-based PCAP analysis engine for inspecting network captures, detecting suspicious wireless traffic, and extracting security artifacts online.



- **[Cisco Meraki Wireless Health & Air Marshal](https://cisco.com)**  

  Cloud-managed wireless intrusion detection and prevention system (WIDS/WIPS) providing automated rogue AP containment and RF analytics.



- **[Acrylic Wi-Fi Analyzer & Heatmaps](https://acrylicwifi.com)**  

  Professional Windows wireless auditing and 802.11 packet analysis suite supporting Wi-Fi 6E/7 spectrum diagnostics and site surveys.



## Open-Source GitHub Projects



- **[Airgorah (martin-olivier/airgorah)](https://github.com)**  

  Modern, user-friendly GTK4 open-source GUI application built on top of the Aircrack-ng suite for Wi-Fi network scanning, deauthentication testing, and WPA/WPA2 handshake capture.



- **[Aircrack-ng](https://github.com)**  

  Complete open-source suite of command-line tools for assessing Wi-Fi network security, focusing on packet capture, replay attacks, deauthentication, and WEP/WPA-PSK cracking.



- **[Kismet](https://github.com)**  

  Open-source wireless network and device detector, sniffer, wardriving tool, and WIDS framework supporting Wi-Fi, Bluetooth, BTLE, Zigbee, and SDR hardware.



- **[Wireshark](https://github.com)**  

  The world's foremost open-source network protocol analyzer for deep inspection of live 802.11 wireless frames, Ethernet packets, and hundreds of network protocols.



- **[Wifite2](https://github.com)**  

  Automated open-source wireless attack and auditing tool for Linux that orchestrates Aircrack-ng, Reaver, Bully, and Hashcat against WEP, WPA/WPA2, and WPS targets.



- **[Bettercap](https://github.com)**  

  Swiss-army-knife open-source network attack and monitoring framework supporting Wi-Fi recon, PMKID/handshake capture, BLE scanning, and IPv4/IPv6 MITM auditing.



- **[hcxdumptool](https://github.com)**  

  Small, high-speed open-source tool designed to capture raw 802.11 frames, PMKIDs, and EAPOL handshakes from WLAN devices for Hashcat auditing.



- **[hcxtools](https://github.com)**  

  Companion open-source utility set for converting captured pcapng wireless traffic into hash formats compatible with Hashcat and John the Ripper.



- **[Hashcat](https://github.com)**  

  World's fastest open-source GPU-accelerated password recovery utility used for auditing captured WPA/WPA2/WPA3 PMKID and EAPOL password hashes.



- **[WiFi-Pumpkin3](https://github.com)**  

  Powerful open-source framework for rogue access point attacks, captive portal auditing, DNS spoofing, and wireless man-in-the-middle testing.



- **[Airgeddon](https://github.com)**  

  Multi-use bash script suite for Linux systems providing an interactive menu for wireless auditing, Evil Twin attacks, WPS PIN testing, and DoS assessments.



- **[Eaphammer](https://github.com)**  

  Open-source toolkit engineered for targeted Evil Twin attacks against WPA2-Enterprise and WPA3-Enterprise networks, credential harvesting, and captive portal testing.



- **[hostapd-mana](https://github.com)**  

  Modified open-source hostapd implementation designed for rogue access point auditing, KARMA attacks, and capturing EAP credentials.



- **[Reaver](https://github.com)**  

  Open-source brute-force auditing tool targeting Wi-Fi Protected Setup (WPS) registrar PINs to recover WPA/WPA2 passphrases.



- **[Bully](https://github.com)**  

  C-based open-source implementation of the WPS brute-force vulnerability featuring lower memory footprint and optimized packet injection handling.



- **[MDK4](https://github.com)**  

  Open-source Wi-Fi testing and proof-of-concept tool exploiting common IEEE 802.11 protocol weaknesses including beacon flooding, authentication DoS, and WIDS confusion.



- **[ Sparrow-WiFi](https://github.com)**  

  Next-generation graphical Wi-Fi and Bluetooth analyzer for Linux offering spectrum monitoring, GPS wardriving integration, and Falcon drone-based recon.



- **[LinSSID](https://github.com)**  

  Open-source graphical Wi-Fi scanner for Linux providing real-time channel overlap graphs, signal strength tracking, and AP security diagnostics.



- **[WaveMon](https://github.com)**  

  Ncurses-based open-source monitoring application for wireless network devices displaying signal/noise levels, packet statistics, and scan results in the terminal.



- **[Horst](https://github.com)**  

  Lightweight open-source IEEE 802.11 wireless LAN analyzer designed for troubleshooting mesh networks, packet types, and channel utilization.



- **[Blue Hydra](https://github.com)**  

  Open-source Bluetooth device discovery and tracking service built on top of BlueZ and Ubertooth for auditing classic Bluetooth and BLE devices.



- **[Gatekeeper / Btlejack](https://github.com)**  

  Open-source Bluetooth Low Energy (BLE) sniffing, connection hijacking, and jamming auditing tool powered by Micro:bit or nRF51 hardware.



- **[OpenVAS / Greenbone Community Edition](https://github.com)**  

  Full-featured open-source network vulnerability scanner and manager offering an open alternative to Nessus and Qualys with daily NVT feed updates.



- **[Nmap](https://github.com)**  

  Industry-standard open-source network discovery and security auditing utility featuring the Nmap Scripting Engine (NSE) for wireless AP and service enumeration.



- **[Zeek (formerly Bro)](https://github.com)**  

  Open-source passive network traffic analyzer and security monitoring framework generating structured logs for anomaly detection and threat hunting.



- **[Suricata](https://github.com)**  

  High-performance open-source Intrusion Detection System (IDS), Intrusion Prevention System (IPS), and Network Security Monitoring (NSM) engine.



- **[WigleWifi Wardriving](https://github.com)**  

  Open-source Android wardriving client for mapping Wi-Fi access points, Bluetooth devices, and cell towers with GPS coordinates.



### Additional Strong Open-Source Options
